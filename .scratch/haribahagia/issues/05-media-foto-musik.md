# 05: Foto dan musik undangan

**What to build:** Sebagai admin, saya dapat menyiapkan foto di bagian yang tepat dan musik undangan, sehingga media muncul ke tamu hanya setelah kontennya diterbitkan.

**Blocked by:** 02 — Login dan akses admin; 03 — Edit dan publikasikan konten.

**Status:** ready-for-agent

- [ ] Admin dapat mengunggah, mengganti, atau melepas foto pasangan di sampul, foto CPP, foto CPW, dan beberapa foto galeri.
- [ ] Admin dapat mengatur urutan foto galeri; galeri tamu tetap berupa grid sederhana tanpa slider atau lightbox.
- [ ] Admin dapat mengisi teks alternatif yang diperlukan untuk memahami gambar.
- [ ] Admin dapat mengunggah atau mengganti musik MP3; musik dan foto yang dipilih tampil di preview dan snapshot publik setelah Publish.
- [ ] Upload hanya diizinkan bagi admin, divalidasi menurut isi/ukuran, dan tidak mengganti media lama saat upload gagal.
- [ ] Media draf tersimpan privat; preview dan undangan hanya menerima signed URL untuk media yang diizinkan.
- [ ] Melepas media dari draf tidak menghapus objek yang masih dipakai snapshot publik.
- [ ] Tombol Buka Undangan mencoba memutar musik setelah interaksi; kontrol putar/jeda tersedia dan kegagalan audio tidak menghalangi konten.
- [ ] Tanpa foto/musik, layout tetap lengkap dan kontrol musik tidak ditampilkan.
- [ ] Foto memakai ukuran tampilan yang sesuai; metadata lokasi dihapus sebelum media dipublikasikan.
