# Domain Docs

Proyek menggunakan satu konteks domain.

Sebelum mengeksplorasi kode, baca GLOSSARY.md dan ADR terkait
dalam docs/adr/ jika tersedia.

Jika belum tersedia, lanjutkan tanpa meminta pembuatannya.
Buat dokumentasi domain ketika ada kebutuhan nyata melalui
alur domain-modeling.

Gunakan istilah dalam glossary secara konsisten.
Jika usulan bertentangan dengan ADR, jelaskan konflik tersebut.
