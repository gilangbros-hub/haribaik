# 01: Undangan publik dasar

**What to build:** Sebagai tamu, saya dapat membuka undangan satu halaman yang responsif dan nyaman digunakan, sehingga desain utama bisa ditinjau sebelum data dan pengelolaan admin dihubungkan.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Proyek Astro + TypeScript berjalan di Vercel adapter dan memiliki renderer undangan publik dengan data contoh.
- [ ] Halaman satu scroll memuat sampul, profil mempelai, detail acara, penutup, tautan peta, unduhan kalender, serta ruang untuk RSVP dan media berikutnya.
- [ ] Warna, tipografi, lebar konten, dan spacing mengikuti acuan Sheilly & Dhanar; empat repo tambahan dipakai sebagai inspirasi pendukung.
- [ ] Layout nyaman pada lebar 320 px, desktop, dan nama panjang tanpa scroll horizontal.
- [ ] Tombol Buka Undangan memindahkan fokus ke isi; navigasi keyboard terlihat, dan reduced motion tidak menyembunyikan konten.
- [ ] Renderer dapat memakai data fixture serta data terstruktur yang kelak diberikan dari server.
- [ ] Kode admin tidak dikirim ke halaman undangan.
